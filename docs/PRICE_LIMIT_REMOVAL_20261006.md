# Удаление ограничения цены Interhub — 06.10.2026

По запросу владельца удалено сравнение актуальной цены поставщика с прежним
`max_amount` Seller. Причина: покупка App Store USA USD 2 от 11:16:48 МСК
остановилась при расчёте 185,46 ₽ и старом лимите 182,41 ₽ ещё до `check/pay`.

## Ревизия и поведение

Код: `e00e60b49209279795c6acfccb600e680fc7cc6e`. Перед поставкой push в
`origin/main` подтверждён, локальный HEAD совпал с удалённой веткой.

Hub использует положительную цену `calculate` для `check/pay` без верхнего
ограничения со стороны сохранённой цены Seller. `max_amount` необязательно;
старые значения и fingerprint сохраняются для совместимости повторных запросов.
Проверка успешности расчёта, state machine, запрет повторного pay и защита от
повторного кода сохранены. Изменения Seller и CRM для этого не требуются.
